# Drone Telemetry Dashboard — Project Script

## Objective
To build a real-time visualization dashboard of drone telemetry data using Python, Dash, and Plotly.

## Data Used
- telemetry_data.xlsx  
Includes:
- Roll, Pitch, Heading  
- Latitude, Longitude  
- Altitude  
- Timestamp  

## Tools
- Python  
- Dash  
- Plotly  
- Pandas  
- VS Code  

## Features
- Live playback simulation  
- Orientation graph  
- Altitude graph  
- GPS path map  
- Telemetry readout  

## How to Run
1. Activate virtual environment  
2. Install dependencies  
3. Run `python app.py`  
4. Open browser  

## Conclusion
The dashboard successfully visualizes drone telemetry and simulates real-time flight behavior.
